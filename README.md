## Publish with GitHub Pages
1. Sign in to GitHub as `richie-stak`.
2. Create a **public** repository named exactly `cybersecurity-analyst`.
3. Upload the contents of this folder to the repository root (not the containing folder).
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then save.
7. Wait for GitHub Pages to finish deploying. The expected address is `https://richie-stak.github.io/cybersecurity-analyst/`, but it is not live or verified until GitHub confirms deployment.

## Before submitting the plugin
- Open the live Home, Privacy, Terms and Support pages in a private/incognito browser window.
- Confirm that each page loads without signing in and that the support email link works.
- Review the Privacy Policy and Terms of Use carefully. They describe the current skills-only plugin design and should be changed if the plugin later gains a backend, integrations or independent data collection.
- Use the exact live page URLs in the plugin listing:
